# ДЗ 1 — профиль железа и бенчмарк

## Железо

Apple M4, 16 ГБ unified memory, macOS 26.3.1. Python 3.12.13, torch 2.14.0, transformers 5.16.1.

## Модель

По таблице железа из лекции 1 (Mac Apple Silicon, 16 ГБ+) выбрана **Qwen3-1.7B**, bf16, устройство MPS. Записана в `params.yaml`. Замер это подтверждает: 4.5 ГБ из 16 и 23 tok/s, запас под LoRA в ДЗ 5 есть.

## Замеры

1 прогрев, 3 прогона, медиана. Загрузка — таймер вокруг `load_model`; tokens/sec — таймер на каждый прогон после прогрева; RSS — `ru_maxrss`, максимум за процесс.

| Устройство | dtype | Загрузка, с | tokens/sec | Прогоны | Пиковая RSS, МБ |
|---|---|---|---|---|---|
| **mps** | **bf16** | 1.01 | **22.9** | 23.31 / 22.79 / 22.89 | 4455 |
| cpu | bf16 | 0.49 | 15.8 | 15.83 / 15.84 / 15.85 | 3758 |
| cpu | fp32 | 2.05 | 9.3 | 9.31 / 9.33 / 9.32 | 7947 |

- MPS быстрее CPU в 1.45 раза.
- На CPU bf16 быстрее fp32 в 1.7 раза и вдвое меньше по памяти: у M4 аппаратный bf16. Замедления bf16, о котором предупреждало задание, здесь нет.
- Разброс между прогонами ≤ 2 %: прогрев работает.
- Ответ заканчивается EOS на 51 токене при лимите 200: модель отвечает одним предложением. На tokens/sec длина не влияет.

`make check`: 5 из 5.

## Дефекты

### 1. Имя модели захардкожено

- **Был**: `"Qwen/Qwen3-0.6B"` в `model.py`, `generate.py`, `bench.py`; `params` в `load_model` не читался.
- **Проявлялся**: смена модели в конфиге ничего не меняла. Grep из check.sh нашёл 2 места из 3: f-строку в `generate.py` он не видит.
- **Исправлен**: везде `params["model"]["name"]`. Имя модели в проекте встречается один раз.

### 2. Зависимости без версий

- **Был**: в `pyproject.toml` только имена пакетов, `uv.lock` и `.python-version` отсутствовали.
- **Проявлялся**: `uv sync` каждый раз разрешал версии заново. Код требует transformers ≥ 4.56 (`dtype=` в `from_pretrained`), на старой версии падает.
- **Исправлен**: Python 3.12 в `.python-version`, у каждой зависимости нижняя и верхняя граница, `uv.lock` закоммичен.

### 3. Бенчмарк мерил загрузку вместе с генерацией

- **Был**: один `t0` до `load_model`, время каждого прогона считалось от него, `load_time = 0.0`, прогрева нет.
- **Проявлялся**: `load_time_sec: 0.0`; `tokens_per_sec: 17` для 0.6B, хотя честный замер 1.7B даёт 23.
- **Исправлен**: отдельный таймер загрузки, прогрев вне замера, таймер на каждый прогон, медиана.

### 4. Генерация не воспроизводилась

- **Был**: `temperature: 0.7` (сэмплинг), `set_seed` написан, но не вызывался.
- **Проявлялся**: два `make generate` дали разный текст, 159 и 87 токенов.
- **Исправлен**: `temperature: 0.0` → `do_sample=False`; `set_seed` вызывается в `generate.py` и `bench.py`. Два прогона совпадают побайтово.

## Воспроизвести

```
uv sync && make generate && make bench && make check
```
