# ДЗ 6+7 — эксперименты и оценка LoRA

Продолжение arXiv из ДЗ 3–5. Qwen3-1.7B обучается генерировать заголовок по аннотации. Шесть конфигураций сравниваются в MLflow при одинаковом бюджете: четыре шага, train-пул 32, val 8, seed 42. Проверка ответов — выбор авторского заголовка из трёх вариантов. Она не заменяет оценку свободной генерации.

Нужны Python 3.12, uv, Docker Compose v2 и свои файлы ДЗ 3–4. Модель закреплена по ревизии в `params.yaml`; после скачивания используется кеш Hugging Face. MLflow: http://127.0.0.1:5006. Обучение выполняется на ноутбуке, сервер и Postgres — в Docker. `make down` сохраняет данные; не используйте `down -v`.

```bash
cd hw6-7
uv sync --frozen
make check-eval
make up
HF_HUB_OFFLINE=1 make sweep
make report
make candidate
make baseline-init
make evaluate
make eval
make check-negative
make promote          # только если make eval завершился успешно
make check-storage
make check-all
```

Отказ по качеству допустим: `champion` не назначается, `candidate` остаётся доступным. `make baseline-update` явно меняет исходную принятую версию после успешного выпуска и сохраняет историю.

## Данные и проверка

`src/prepare_eval.py` готовит 50 примеров из test, три проверки поведения и полный исходный индекс train. Повторная подготовка не перезаписывает ручную разметку. Источники, версии файлов и связь с токенизированным train сохранены в `data/eval/provenance.json`. Формат оценки описан в [EVALUATION.md](EVALUATION.md).

Проверочные данные хранятся в DVC: `data/eval.dvc`. Для восстановления нужны DVC 3.67.1 и `context/hw6-7-submission.zip`. Распакуйте архив в каталоге `hw6-7`, сохранив структуру `context/submission/`, затем выполните `dvc pull`. Архив содержит данные DVC и отчёты без весов, обучающих тензоров и секретов.
