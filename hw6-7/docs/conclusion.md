# Выбор и оценка адаптера arXiv

## Обучение и выбор

Qwen3-1.7B генерирует заголовок по аннотации из своих данных ДЗ 3–4. Шесть конфигураций LoRA сравнивались при одинаковых train-пуле 32, val 8, seed 42 и четырёх шагах: batch 1, накопление 2. Менялись r, lr и проекции. Test не участвовал в выборе. Версии входов, исходники и uv.lock сохранены в MLflow.

Выбран `all-r8-high`: r=8, lr=0,0003, все семь проекций. Val loss: 7,5689 → 2,5424; отношение — 0,3359. Обучение с валидацией — 17,52 с; весь поиск с загрузкой и сохранением — 322,2 с. Ресурсы приведены в таблице сравнения.

[Таблица шести запусков](comparison.csv). Кандидат: `models:/arxiv-title-qwen3-1-7b/1`. [Запуск кандидата](http://127.0.0.1:5006/#/experiments/1/runs/d9a54c5e83d4496d9fafdadcfcf7d30d).

## Протокол оценки

До оценки были отобраны 50 примеров из test. Эталонные ответы и однозначность вариантов проверены вручную по русским переводам. Данные, источники, разметка и результаты проверки сохранены в DVC. Полный индекс train: 45 772 исходные записи, покрывающие 45 575 токенизированных примеров. Пересечений id и категорий с оценкой не обнаружено; смысловые совпадения полностью не исключены.

Проверяется выбор авторского заголовка из трёх вариантов, а не свободная генерация. Обе версии получают одну инструкцию, seed 42, do_sample=False и лимит 32 токена. Формат: JSON с единственным строковым полем `answer` из choices. Все ответы остаются в знаменателе. Ревизия базы: `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`.

Все три области заранее объявлены критическими: общие accuracy и format_rate и accuracy каждой области не ниже базы; все проверки поведения проходят. Допуск ухудшения — ноль. После генерации данные и пороги не менялись.

## Разбор четырёх пар ответов

- `arxiv:0809.2365`, эталон A: Аннотация прямо рассматривает непериодическую систему в части I, а периодическую часть II называет будущей работой. База выбрала A, кандидат — B: потеря существенного условия.
- `arxiv:0810.4902`, эталон C: Обе версии выбрали REFUSE вместо C. Заголовок связан с упомянутыми Richard, Tom и Robert; научная аннотация об эксперименте со скоростью комаров ошибочно отклонена. Пример сохранён в знаменателе.
- `arxiv:1006.1450`, эталон A: Обе версии выбрали A. Заголовок отражает разделение работы агента и межагентной координации через активируемые модули DECOMAS. Остальные варианты описывают другие способы организации систем.
- `arxiv:1104.5341`, эталон B: Обе версии выбрали B. В аннотации совместно оцениваются несколько LiNGAM с общим причинным порядком; альтернативы добавляют скрытые факторы либо ограничение числа наблюдений.

## Решение и ограничения

**Кандидат не принят в champion.** Ухудшились общая accuracy и критический математический срез; не пройдена проверка отказа. База не заменена. `candidate` остаётся доступным. Отрицательная проверка отклонила копию с испорченными ответами; счётчики пересчитаны из этих ответов, реальные веса и имена в реестре не менялись.

Снижение val loss не гарантирует улучшения ответов. На 50 заданиях при одном seed различие в один ответ не доказывает устойчивого ухудшения. Результат базы близок к максимуму. Следующий шаг — проверить инструкцию отказа и соответствие обучения форме ответа на другом наборе. Повторное использование текущего набора не является независимой оценкой.

ROUGE измеряет совпадение слов, которое не гарантирует верного выбора части I вместо II. Модель-судья полезна для оценки смысла свободных заголовков, но чувствительна к порядку и подробности ответов. Нужны скрытые имена моделей, перестановка A/B и сверка человеком. Для меток использовано программное сравнение без модели-судьи.
