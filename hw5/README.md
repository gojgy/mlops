# ДЗ 5 — LoRA для заголовков arXiv

Qwen3-1.7B получает аннотацию научной статьи и генерирует английский заголовок. Использованы свой датасет ДЗ 3 и тензоры ДЗ 4.

Итоговый адаптер — `models/experiment3k/adapter_all_layers`: LoRA на всех 28 слоях, 3072 примера, одна эпоха, 384 шага. Выбран за компактную форму заголовков; устойчивое улучшение точности не заявляется. Результаты — в [разборе дефектов](docs/defects.md) и [сравнении ответов](docs/compare.md).

Для эксперимента с заморозкой сохранены два прогона на одинаковых 512 train / 128 val: `all_layers` и `freeze14` (LoRA только в блоках 14–27). Их кривые — `docs/curves.png`. Базовые веса заморожены во всех прогонах. Итоговый адаптер использует те же 128 val.

## Запуск

Нужны `hw4/data/tokenized/train.pt`, `val.pt` для Qwen3-1.7B и скачанные веса модели. `params.yaml` задаёт контрольное сравнение слоёв, `params.final.yaml` переопределяет размер выборки и пути итогового прогона; остальные настройки общие. Конфигурации разделены, чтобы сохранить одинаковую выборку для сравнения слоёв.

```bash
cd hw5
uv sync --locked
make prepare             # контрольные 512 train / 128 val
make train               # оба варианта и график
make prepare-final       # итоговые 3072 train / 128 val
make train-final         # итоговый all_layers, около 95 минут на данном ноутбуке
make compare             # база и итоговый адаптер; контрольные ответы для check
make check               # девять исходных проверок контрольного эксперимента
```

Сохранённые адаптеры уже обучены; для просмотра ответов повторять обучение не нужно. Команды используют кеш Hugging Face без сети. Для первого скачивания: `HF_HUB_OFFLINE=0 make train`.

Microbatch 1, накопление градиентов 8, lr `2e-4`, seed 42. Валидация до обучения, каждые 10 шагов и в конце. На Apple Silicon — MPS, bf16 и gradient checkpointing. На CPU задайте dtype float32. Короткая проверка итоговой конфигурации: `uv run python -m src.final train --max-steps 3 --val-limit 8 --out models/smoke`.

## Файлы

| Файл | Назначение |
|---|---|
| `src/prepare_data.py` | Выборка тензоров ДЗ 4 без повторной токенизации |
| `src/train.py` | LoRA, обучение, валидация, сохранение токенизатора |
| `src/final.py` | Те же стадии с итоговой конфигурацией |
| `src/compare.py` | Жадная генерация базы и адаптера на пяти одинаковых входах |
| `src/plot.py` | Кривые контрольного сравнения слоёв |
| `dvc.yaml` | Зависимости контрольных и итоговых стадий |
| `tests/check.sh` | Исходная самопроверка; отпечаток `06a02208c1f0` |

Адаптеры, тензоры и метрики остаются локально; в Git входят код, конфигурации, lock-файл и отчёты. Итоговый адаптер также проверен после копирования: независимая офлайн-загрузка воспроизвела пять ответов. На другой машине нужны отдельно скачанные базовые веса. `make clean` удаляет результаты, `make distclean` — также окружение.
