# Datasheet: заголовок статьи arXiv по аннотации

**Задача.** Модель получает аннотацию научной статьи и отвечает её заголовком.

```json
{"id": "arxiv:0704.1827", "topic": "cs.DC", "messages": [
  {"role": "system",    "content": "Given the abstract of an arXiv paper, produce a concise, informative title. …"},
  {"role": "user",      "content": "<аннотация>"},
  {"role": "assistant", "content": "Transaction-Oriented Simulation In Ad Hoc Grids"}]}
```

`topic` — основная категория arXiv, она же группа сплита.

## Источник и лицензия

Официальная выгрузка метаданных arXiv, лицензия **CC0 1.0**, зеркало
[`gfissore/arxiv-abstracts-2021`](https://huggingface.co/datasets/gfissore/arxiv-abstracts-2021).
Берётся первый parquet-шард: 433 421 статья, апрель 2007 — май 2013, 302 МБ.
Источник открытый: стадия `fetch` скачивает файл и сверяет sha256. В git файл
не попадает, он под управлением DVC.

## Что взято и что сделано руками

Взяты поля `id`, `title`, `abstract`, `categories`. Вся переработка —
в `src/collect.py`, каждое действие — счётчик в `metrics/collect.json`:

| Действие | v1 | v2 |
|---|---:|---:|
| просмотрено строк источника | 433 421 | 433 421 |
| **сужение:** основная категория не из cs / math / stat | −290 999 | −290 999 |
| **сужение:** год подачи вне окна версии | −96 745 | −15 189 |
| **проверка:** отозванные статьи («This paper has been withdrawn…») | −195 | −310 |
| **проверка:** аннотация короче 200 символов | −3 187 | −7 452 |
| **проверка:** производный заголовок («Part II», «Erratum», «Comment on…») | −150 | −390 |
| **проверка:** заголовок дословно стоит в аннотации | −1 405 | −4 028 |
| выборка 50% по `sha1(id)` | −20 252 | −57 544 |
| **записано в raw.jsonl** | **20 488** | **57 509** |
| **починка:** заголовков, разорванных переносом строки | 6 650 | 19 922 |
| **обогащение:** вариантов системного промпта (в источнике инструкции нет) | 5 | 5 |

- Один `cs` взять нельзя: в нём 40 категорий (гейт требует ≥ 50), `cs.IT` — 18,7%.
- Выборка по хэшу, а не «первые N строк»: равномерна по времени, v2 включает v1.
  Доля 0,5, потому что пара дублей переживает выборку с вероятностью share²:
  на полном срезе v2 дедупликация снимает 225 строк, при доле 0,1 на v1 — ни одной.

## Разнообразие

Пороги гейта **не менялись**, датасет проходит исходные:

| Порог | Требование | v2 |
|---|---|---:|
| `min_examples` | ≥ 1000 | 57 448 |
| `min_system_prompts` | ≥ 3 | 5 |
| `min_groups` | ≥ 50 | 75 |
| `max_group_share` | ≤ 0,10 | 0,066 (`math.PR`) |
| `min_answer_len_ratio` | ≥ 1,6 | 2,53 |
| `max_same_length_share` | ≤ 0,25 | 0,018 |
| `max_duplicate_answer_share` | ≤ 0,30 | 0,0002 |

Состав: math — 69%, cs — 28%, stat — 3%.

## Очистка

Схема → длины → ПДн → точная дедупликация → near-dup (MinHash, Жаккар ≥ 0,85).

- **Дубли:** 30 точных и 31 почти-дубль в v2. Это повторные подачи одной
  статьи под новым id. У 28 пар из 31 заголовки разные — без near-dup у одной
  аннотации было бы два «правильных» ответа. Пример: `0705.0738` «The Optimization
  of a Novel Prismatic Drive» и `0707.3534` «The Kinetostatic Optimization of…», Жаккар 0,95.
- **ПДн:** замаскированы 3 адреса почты («Contact: …»). Правило для телефона
  ужесточено: исходное принимало за номер число `82462576220` из аннотации
  по теории чисел.

## Сплит и контаминация

- Группа — основная категория arXiv, целиком уходит в один сплит:
  **test состоит из областей, которых модель не видела**.
- Группы раздаются в случайном порядке (seed 42) в сплит с наибольшим
  относительным недобором доли. Фактические доли v2: 79,7 / 10,0 / 10,3.
- `split.max_eval_group_share = 0.25`: группа крупнее четверти целевого объёма
  val/test идёт только в train. Без этого одна категория занимала до 58% test;
  с ним в val и test по 13 категорий, крупнейшая — 20% и 23%.
- **Контаминация — ноль** по id, тексту, группам и near-dup парам. Проверяется
  дважды: стадия `split` падает при пересечении, плюс отдельная стадия
  `contamination`. Порог near-dup тот же, что в очистке.

## Чего датасет не покрывает

- Только английский язык и только 2007–2012 годы: современных тем (LLM,
  диффузионные модели) и нынешнего стиля заголовков в наборе нет.
- Перекос в математику — 69% строк; физика, биология, экономика исключены.
- Крупнейшие категории никогда не попадают в test.
- Сплит по категориям строже сплита по статьям: метрика на test ниже, чем
  при случайном сплите, и несравнима с чужими результатами на arXiv.
- LaTeX в аннотациях и заголовках оставлен как в источнике.
- Заголовок не всегда выводим из аннотации: авторы используют термины,
  которых в ней нет.
- Порог 0,85 ловит повторные подачи, но не вольные пересказы.
